# data

Static reference config, versioned in git, no PII.

- `offices.json` -- the 5 elected offices in ballot presentation order.
- `states_nigeria.json` -- 36 states + FCT with geopolitical zone.
- `parties_nigeria.json` -- ~15 real INEC-registered party names/acronyms with a
  UI display color and, where a verifiable logo image was found, a `logo` path
  into `party_logos/`. Reconfirm against INEC's current register before relying
  on this for anything beyond a demo -- see
  [../docs/NIGERIA_ELECTION_MODEL.md](../docs/NIGERIA_ELECTION_MODEL.md).
- `party_logos/` -- real party logo images, fetched/regenerated by
  `scripts/fetch_party_logos.py`; not every party has one (see
  `party_logos/ATTRIBUTION.md` for sources/licenses and
  [../docs/DISCLAIMER.md#party-logos](../docs/DISCLAIMER.md#party-logos) for the
  fair-use rationale and its limits). Parties without a sourced logo render as a
  color+acronym card instead -- see `hand_ui/renderer.py::draw_region`.
- `phrases/{en,yo,ig,ha}.json` -- every spoken UI phrase, keyed by `phrase_id`, each
  `{"text": ..., "review_status": ...}`. `en.json` is the canonical source
  (`review_status: "source"`); the other three are machine-drafted
  (`review_status: "machine_draft_unreviewed"`) and need the process in
  [../docs/TRANSLATION_REVIEW_CHECKLIST.md](../docs/TRANSLATION_REVIEW_CHECKLIST.md)
  before real use. All four files must contain exactly the same set of `phrase_id`
  keys -- checked by `voice/tests/test_phrase_registry.py`.
